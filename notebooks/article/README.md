# `notebooks/article/` - pilot notebooks (Fase H3.5, development)

**These nine notebooks (`A00`-`A07`) are pilot/development artifacts.**
They load the small-scale `C01`-`C04` campaigns (`results/raw/C0*`,
20 seeds or fewer, built to validate the pipeline end-to-end during
Fase H3) - they are **not** the final evidence base for the article.

They are kept and still pass the notebook test suite (they double as a
regression check on the pipeline itself), but no figure, table, or
number from this folder should be cited in the article. The
`docs/results_provenance.md` table marks every one of them
`pilot_only`.

**For the final campaigns (F01-F08, 20 seeds, the article's actual
evidence base), see [`notebooks/article/final/`](final/) instead.**
